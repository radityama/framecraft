# Framecraft export

Repository Markdown guide, not a provider-installed dependency. Run `bun run validate`, inspect retained review PNGs, record a named decision and pass `bun run review --check <manifest>` before `bun run render`. Use `--project <path> --scene <id>` consistently on validation, review and export; omit them for demo/intro. Export targets one selected scene or `--shot <id>` within it, not an entire multi-scene project. Consult `docs/rendering.md` for commands and its bundled FFprobe stream probe; confirm dimensions, decoded frame count, duration, fps, video and audio codecs. `bun test` includes real audio-export regression checks. Note unperformed cross-machine or human listening checks rather than implying them.
