# FRAMECRAFT / MOTION STUDIES VOL. 02

Approved direction: **The frame becomes the system**. A 55-second silent editorial film, 1920×1080 at 30 fps. One scene, four independent HTML shots, 1650 frames. No changes to the renderer or existing projects.

## The four movements

1. **Wake / 0–360:** oversized masked letter choreography makes EVERY FRAME / HAS INTENT. A typographic counter becomes an orange signal; a cropping frame becomes a desktop window. Scale and framing have a narrative job, not random motion.
2. **Desktop / 360–810:** original Framecraft production desk. Source, Frame Inspector and Publish windows overlap. A continuous cursor focuses Source, drags it, resizes Inspector, minimizes Source and clicks Publish. The resulting publication receipt expands into the next sequence.
3. **Story / 810–1260:** SOURCE → PROCESS → VERIFY → PUBLISH. Inputs branch into typography and geometry, merge into deterministic rendering, pass pixel/seek verification and produce a film. A guided camera follows the signal, then resolves to an overview.
4. **Resolve / 1260–1650:** 32 independently choreographed production records retain their four-stage meaning while organizing into a compact ledger. The ledger and inherited diagram yield to individually revealed FRAMECRAFT letters, MOTION, ENGINEERED. and a quiet readable final hold.

## Visual system

Near-black #101114, warm paper #F2F0E9, orange #FF623E reserved for the currently active operation, and gray #8D9199. IBM Plex Sans supplies industrial editorial typography; Plex Serif supplies the contrasting word INTENT; JetBrains Mono supplies frame coordinates and production labels. All fonts and licenses are local. Rectangular masks and corner brackets repeat because the frame is the central idea. Windows have real title bars, focus differences and functional simulated controls, not arbitrary cards.

## Timing and implementation

Four HTML entries load an unchanged project-local runtime and copied Phase 4 motion primitives. Shared film.js renders complete absolute state from `ctx.frame + shot offset`. Shared geometry straddles shot boundaries, avoiding visual jumps without overlapping manifest entries. No wall-clock animation, randomness, network assets or new runtime. All DOM properties that vary are overwritten on every seek.

## Acceptance and evidence

Four retained production passes: blocking PNGs; motion-refined complete MP4 and review; identified editorial revisions with matched captures; final MP4 and verification. Review first/last, movement, target clicks, cuts, complexity and title frames. Open retained PNGs before decisions. Record frame-specific severity, corrections and rechecks. Verify cursor target rectangles/focus, 32 independent record transforms, font files and browser errors, reverse/random seeks and repeated pixel hashes. Run existing tests, validation and typecheck. Probe final H.264 dimensions, fps, frame count and duration. Agent acceptance is preliminary, not human approval or cross-machine determinism.

No commits, no new dependencies, no broad cleanup. Evidence lives outside the selected project because source digests include its entire tree. Low-memory machine: sequential full-resolution exports.
