# Framecraft sound

Repository Markdown guide, not a provider-installed dependency. Declare cues in the selected scene or shot manifest, not HTML; see `docs/audio.md` for frame-based placement, trims, fades and gain. Use supplied local WAV/MP3 media inside that project. Scene exports include only that scene's audio; shot-only exports omit the scene bed. Narration is opt-in only when local media is supplied; do not generate it. Preview in Studio, run audio tests and probe the exported audio stream using the same `--project <path> --scene <id>` selection; neither a stream probe nor tests prove a human listening check.
