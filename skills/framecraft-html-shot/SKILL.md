# Framecraft HTML shot

Repository Markdown guide, not a provider-installed dependency. Follow the public HTML shot API in `AGENTS.md`; do not call the internal bridge. Keep runtime, fonts and assets inside the selected project and render complete state for every shot-local frame, including backward seeks. Register shots in the selected scene manifest; shot IDs are unique within that scene, not across the project. Check early, middle and last frames with `bun run snap --project <path> --scene <id> --shot <id> --frame <local-frame>`; use the same selectors with `bun run studio` for interactive seeking. Omit selectors for demo/intro. See `docs/rendering.md` for export boundaries.
