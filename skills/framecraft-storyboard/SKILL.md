# Framecraft storyboard

Repository Markdown guide, not a provider-installed dependency. Read `AGENTS.md`, the selected project's `project.json`, its selected `scene.json` and the scene's brief. Defaults are `projects/demo`/`intro`, whose brief is inferred, not a client request. Record each shot ID, duration, intent, reveal milestone and cut; do not invent additional requirements. Keep zero-overlap cuts aligned with that scene's manifest. Plan and export one selected scene at a time using `--project <path> --scene <id>`; shot IDs may repeat in other scenes.
