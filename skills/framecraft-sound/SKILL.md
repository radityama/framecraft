# Framecraft sound

Repository Markdown guide, not a provider-installed dependency. Declare cues in the scene or shot manifest, not HTML; see `docs/audio.md` for frame-based placement, trims, fades and gain. Use supplied local WAV/MP3 media inside the demo project. Narration is opt-in only when local media is supplied; do not generate it. Preview in Studio where possible, run audio tests and probe the exported audio stream; neither a stream probe nor tests prove a human listening check.
