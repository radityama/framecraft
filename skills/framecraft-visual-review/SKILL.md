# Framecraft visual review

Repository Markdown guide, not a provider-installed dependency. For the current demo, read its inferred `brief.md`, then run `bun run review --output <new-directory> --milestone title:20 --milestone diagram:30 --milestone commit:60 --milestone commit:90`. Open **every** PNG listed in `manifest.json` individually, including both sides of each cut. Record factual findings by shot/local/global frame, or say explicitly that no defect was observed against the brief. If a defect warrants an HTML fix, preserve the old artifact, change only the affected source, recapture into a **new** directory and inspect again. Only after inspection, edit the manifest's `review` status, named reviewer, findings and notes; run `bun run review --summary <manifest>` and `bun run review --check <manifest>`. Neither capture, hash nor checker automatically judges visual quality. Do not claim human review unless a human performed it.
