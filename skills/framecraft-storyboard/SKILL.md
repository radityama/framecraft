# Framecraft storyboard

Repository Markdown guide, not a provider-installed dependency. Read `AGENTS.md`, `projects/demo/project.json`, `projects/demo/scenes/intro/scene.json`, and the scene's brief (`brief.md` for this demo). Record each shot ID, duration, intent, reveal milestone and cut. Treat the demo brief as inferred, not a client request; do not invent additional requirements. Keep zero-overlap cuts aligned with the manifest. The renderer currently exports only the statically registered demo intro scene.
